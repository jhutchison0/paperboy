# Gap Register

What this repo cannot see yet. Each gap names the collector that would close it and the decision it blocks; a gap with neither is not a gap. The list is never empty: an empty list is a finding about the people keeping it, not evidence the system is clean. Rule 5 of [maintaining-the-common-operating-picture](../.claude/skills/maintaining-the-common-operating-picture/SKILL.md).

A gap is never deleted. It closes when a collector now covers it or a measurement found it absent, and it is superseded when a newer row restates it. Either way the row keeps its place and its Status becomes `closed YYYY-MM-DD by <pointer>` or `superseded YYYY-MM-DD by <pointer>`, the pointer naming the probe, record, or row that replaced it. [tests/test_gaps.py](../tests/test_gaps.py) counts `open` rows only and fails when none remain, when an open row lacks either field or leaves its Gap cell empty (a filler such as `TBD` or `None exists.` alone counts as lacking it), or when a Status takes any other form. Keep the header as it is, and put no `|` character in a cell.

A gap is not a defect. Something with a known fix is a task in [docs/tasks.md](tasks.md); something nobody can measure is a gap. Every number quoted in a cell carries the date it was taken and the collector that took it: the register has no stamp of its own, so a bare number here would be an estimate wearing a measurement's clothes (rule 2). A collector names an observation that could come out either way, with the universe it searches and what it is blind to; the designs for G3 and G4 are in [docs/reviews/20261022_gap_register_ds_review.md](reviews/20261022_gap_register_ds_review.md).
